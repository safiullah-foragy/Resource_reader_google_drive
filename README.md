## 🇧🇩 বাংলা বিবরণ (Bengali Overview)

### 📌 ড্রাইভ স্টুডিও (Drive Studio) কি?
**Drive Studio** হলো একটি আধুনিক, দ্রুতগতির এবং সম্পূর্ণ ক্লায়েন্ট-সাইড **মাল্টি-ক্লাউড ও লোকাল ফাইল ম্যানেজার + ডকুমেন্ট এডিটর/রিডার**। 
এটি আপনাকে আপনার কম্পিউটারের **Local Drive** এবং একাধিক **Google Drive (Drive 1, Drive 2 ইত্যাদি)** অ্যাকাউন্ট কোনো লগআউট ছাড়াই পাশাপাশি ব্রাউজার ট্যাবে ব্যবহারের সুযোগ করে দেয়। এর মাধ্যমে PDF পড়া ও মার্ক করা, Excel শিট এডিট করা, ছবি ও ডকুমেন্টস সরাসরি ব্রাউজারেই প্রিভিউ ও সেভ করা যায়।

---

### ✨ মূল বৈশিষ্ট্যসমূহ (Key Features):

1. **⚡ একসাথে একাধিক গুগল ড্রাইভ ও লোকাল ড্রাইভ (Multi-Account Tabs)**:
   - কোনো অ্যাকাউন্ট লগআউট না করেই **Local Drive**, **Drive 1 (Personal)**, **Drive 2 (Work/University)** ট্যাবে এক ক্লিকেই ড্রাইভ পরিবর্তন করুন।
   - **`+ Add Drive`** বাটনে ক্লিক করে যত খুশি গুগল ড্রাইভ যুক্ত করুন।

2. **📖 স্মার্ট PDF রিডার ও পেজ মেমোরি (Smart Auto-Resume)**:
   - PDF ফাইল পড়ার সময় আপনি কত নম্বর পেজে ছিলেন তা স্বয়ংক্রিয়ভাবে মনে রাখে।
   - পরবর্তীতে ফাইলটি ওপেন করলে স্ক্রোল ছাড়াই সরাসরি আপনার শেষ পড়া পেজে চলে যায়।

3. **✏️ সরাসরি ব্রাউজারেই এডিটিং ও সেভ (In-Place Editor)**:
   - **PDF**: হাইলাইট, ফ্রিহ্যান্ড ড্রইং, টেক্সট নোট, জুম, পেজ নেভিগেশন।
   - **Excel (XLSX/CSV)**: স্প্রেডশিট গ্রিড ভিউ এবং সেল ডেটা এডিটিং।
   - **Images & Docs**: ছবি ফিল্টারিং/ঘুরানো এবং টেক্সট/ওয়ার্ড ডকুমেন্ট রিডিং।
   - ড্রাইভের ফাইল ড্রাইভে এবং লোকাল ফাইল কম্পিউটারে সেভ হয়।

4. **🔄 ইউনিভার্সাল ক্রস-ড্রাইভ কপি ও পেস্ট (Cross-Drive Copy/Paste)**:
   - লোকাল ড্রাইভ থেকে ফাইল কপি করে গুগল ড্রাইভে বা ড্রাইভ ১ থেকে ড্রাইভ ২-এ সরাসরি পেস্ট করতে পারবেন।

5. **📁 উন্নত ফাইল ও ফোল্ডার ব্যবস্থাপনা (Full File Management)**:
   - ফোল্ডারের ভেতরে নতুন সাব-ফোল্ডার তৈরি (`+ New Folder`)।
   - যেকোনো ফরম্যাটের ফাইল আপলোড (PDF, Images, Docs, Excel ইত্যাদি)।
   - কীবোর্ড শর্টকাট: `Delete` চাপলে ডিলিট, `Ctrl+C` কপি, `Ctrl+X` কাট, `Ctrl+V` পেস্ট।
   - ১-ক্লিকে সিলেক্ট, ডাবল-ক্লিকে ওপেন, ফোল্ডার ব্যাক (`<`) ও ফরোয়ার্ড (`>`) বাটন।

6. **🎨 ৫টি প্রিমিয়াম থিম ও UI জুম স্কেলিং (Themes & Scaling)**:
   - **৫টি থিম**: Midnight Dark 🌙, Pure Light ☀️, Cyberpunk Neon 🌌, Forest Emerald 🌲, Warm Amber/Coffee ☕।
   - **রেস্পন্সিভ জুম**: ৮০% থেকে ১৪০% পর্যন্ত পুরো অ্যাপের টেক্সট ও কার্ড ছোট-বড় করার সুবিধা।

7. **🔒 ১০০% নিরাপদ ও প্রাইভেট (Zero-Data Logging)**:
   - কোনো ব্যাকএন্ড সার্ভার বা ডেটাবেজ নেই। সমস্ত ডেটা ও টোকেন ইউজারের নিজস্ব ব্রাউজারে সংরক্ষিত থাকে।

### 🚀 কিভাবে ব্যবহার করবেন? (How to Use):

1. **[https://drive-studio.onrender.com](https://drive-studio.onrender.com)** লিংকে যান।
2. **লোকাল ড্রাইভ ব্যবহার করতে**: **`Browse Local Drive / Folder`** ক্লিক করে আপনার পিসির যেকোনো ফোল্ডার নির্বাচন করুন।
3. **গুগল ড্রাইভ ব্যবহার করতে**: **`Connect Google Drive`** বা **`+ Add Drive`** বাটনে ক্লিক করে আপনার জিমেইল সিলেক্ট করুন।
4. **ফাইল ওপেন করতে**: যেকোনো ফাইলে **ডাবল ক্লিক (Double Click)** করুন।
5. **ফাইল কপি/কাট/মুভ করতে**: ফাইল সিলেক্ট করে `Ctrl+C` বা `Ctrl+X` চাপুন, গন্তব্য ফোল্ডারে গিয়ে `Ctrl+V` চাপুন।
6. **থিম বা জুম পরিবর্তন করতে**: উপরের ডানপাশের **সেটিংস (⚙️)** আইকনে ক্লিক করুন।

## 🇬🇧 English Overview

### 📌 What is Drive Studio?
**Drive Studio** is a modern, ultra-responsive, privacy-first **multi-cloud workspace, document reader, and lossless editor**. It unifies your offline **Local Storage** and multiple **Google Drive accounts (Drive 1, Drive 2, etc.)** into a unified tabbed interface without requiring constant logouts or account switching.

---

### 🌟 Key Highlights:

- **Simultaneous Multi-Drive Tabs**: Run Local Drive, Personal Drive, and Work/University Drives side-by-side.
- **Smart PDF Page Memory**: Auto-scrolls directly to the exact page you last read when re-opening documents.
- **Built-in Lossless Editors**:
  - **PDF Studio**: Annotation, highlight, draw, text, zoom, and lossless in-place sync.
  - **Excel Grid**: Multi-sheet viewing, editing, formula cells, and XLSX export.
  - **Images & Docs**: Rich image viewer/editor and document parser.
- **Universal Cross-Drive Paste**: Transfer files effortlessly between Local Drive ↔ Google Drive 1 ↔ Google Drive 2 with `Ctrl+C` / `Ctrl+X` / `Ctrl+V`.
- **Complete File Manager**: Folder creation at any depth, multi-file uploads, single-click selection, double-click open, folder history navigation (`<` / `>`).
- **5 Curated Color Themes**: Midnight Dark, Pure Light, Cyberpunk Neon, Forest Emerald, and Warm Amber.
- **Adaptive UI Zoom Scaling**: 80% to 140% fluid scale controls with auto-reflowing grid.
- **100% Privacy Guarantee**: Zero backend servers; all OAuth tokens and files remain exclusively on your device.

---

### ⌨️ Keyboard Shortcuts:

| Shortcut | Action |
|---|---|
| `Single Click` | Select file or folder |
| `Double Click` / `Enter` | Open file in new tab or enter folder |
| `Delete` / `Backspace` | Delete selected file (Folders protected) |
| `Ctrl + C` (or `Cmd + C`) | Copy selected file to clipboard |
| `Ctrl + X` (or `Cmd + X`) | Cut selected file for moving |
| `Ctrl + V` (or `Cmd + V`) | Paste file into current directory |
| `Escape` | Deselect current file |

## 🛠️ Local Development & Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `pnpm`

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/safiullah-foragy/Resource_reader_google_drive.git

# 2. Enter directory
cd Resource_reader_google_drive

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open `http://localhost:5173` in your browser.

### Production Build
```bash
npm run build
```

## 🛡️ Security & Privacy
- **Client-Side PKCE / GIS**: Authenticates securely using official Google Identity Services.
- **No Third-Party Server**: Your files travel directly between your browser and Google's official endpoints (`googleapis.com`).
- **Token Revocation**: Disconnecting a Drive account explicitly revokes access tokens.
